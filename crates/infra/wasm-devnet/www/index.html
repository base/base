PIPELINE_TOPOLOGY:

  • L1_MOCK : Mines L1 blocks every epoch.
  • SEQUENCER : Produces L2 blocks continuously.
  • BATCHER : Compresses L2 blocks into calldata (RLP+zlib) & submits to L1.
  • VALIDATOR : Runs the real base-consensus-derive pipeline to independently re-derive L2 blocks from L1 batch data.
